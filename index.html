AI 기반 설계 자동화 플랫폼

EMC 솔루션은 부품·설계·소재 간 상호작용이 많아 고난도 시스템 설계 역량이 필요합니다. 20년 이상의 EMC 제어 경험을 바탕으로 AI 플랫폼 서버와 설계 자동화를 구축해 제품에 적용하고 있습니다.

AI 플랫폼 기반 HW 설계 자동화

회로·부품·구조·소재 설계와 성능·신뢰성 예측을 하나의 AI 플랫폼 서버로 연결하고, 자동 구조 설계와 도면 생성으로 개발 리소스를 줄입니다.

개발 기간3개월 → 2주

Full 3D 설계 플랫폼

22년간 쌓은 EMC 설계 노하우를 Full 3D 설계 환경에 담아, 제작 전 단계에서 방사 노이즈와 공진 포인트를 예측합니다.

ANSYS협력 중

회로 해석·EM 시뮬레이션·실측 결과를 비교해 검증하며, 시뮬레이션 결과만으로 고객사의 기술 채용을 이끌어냅니다.

SOFTWARE R&D

로보틱스 AI 선행 연구

센서 데이터 수집부터 작업 계획, 손가락 단위 제어까지 — 로봇이 사람의 말을 이해하고 움직이게 하는 소프트웨어

  1. 01

    MoAI 혼합 지능 시스템

    로봇의 다중 센서 데이터를 상시 수집해 Data Lake에 쌓고, 전처리·라벨링·자체 학습 리소스로 이어지는 자가 학습 루프를 구성합니다. 실제 현장 데이터로 로봇과 도메인에 특화된 정밀도를 높입니다.

    음성시각라이다촉각상호작용·명령

    공통 데이터 규격

    • 로그 컨테이너 MCAP · ROS 2 bag 호환
    • 센서·보드 단위 타임스탬프 동기화
    • REP-103 좌표계 · SI 단위
    • ASAM OpenLABEL 정답 라벨
  2. 02

    음성-LLM 직결 경로

    음성을 텍스트로 바꾸는 STT 단계를 건너뛰고, 오디오 인코더를 LLM에 직접 연결합니다. 양자화와 Speculative Decoding, NPU 최적화로 온디바이스에서 응답 지연을 줄입니다.

    직접 AV 인코딩양자화토큰 스트리밍Speculative Decoding
    기존음성STT텍스트LLM
    ZEPHYROS음성AV 인코더LLM
  3. 03

    단위 작업 분할 · 토큰 클러스터링

    자연어 복합 명령을 로봇이 실행할 수 있는 최소 단위 동작으로 분해하고, 비슷한 동작을 기능별 클러스터로 묶어 LLM이 고려할 선택지를 줄입니다. 의존성·물리 제약·안전 정책을 반영해 실행 순서를 만들고, 위험한 명령은 걸러냅니다.

    제조물류가사

    "컵을 들어서 테이블 위에 놓고, 뚜껑을 열어라"

    이동집기놓기비틀기
    MOVE_CLGRASP_CLMANIP_CL
  4. 04

    손가락 구동 제어 모듈

    손 랜드마크 추적으로 사람의 손동작을 로봇팔 관절 각도로 실시간 변환하고, Mesh Wi-Fi로 다축 모터를 그룹 단위로 저지연 제어합니다. 내부 제어는 정밀해지되, LLM에는 소수의 고수준 행동 토큰으로 정규화해 전달합니다.

    MediaPipeMesh Wi-FiGRASP_PRECISIONGRASP_POWERFINE_TUNE
  5. 05

    온디바이스 인지 검증 Tool

    Android 앱으로 음성과 영상을 입력받아 Wi-Fi로 자사 서버의 경량 비전 언어 모델을 구동하고, 모델이 사물을 어떻게 인지했는지 앱에서 바로 확인합니다.

    AndroidSTT · TTS비전 언어 모델로컬 서버
